# Instrucciones para agentes

Antes de analizar o modificar este repositorio, lee completo
[`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md).

Después de cada cambio:

1. valida el código y las vistas afectadas;
2. conserva el trabajo local preexistente;
3. actualiza `PROJECT_CONTEXT.md` con la fecha, resultado, archivos, pruebas y pendientes;
4. mantén compatibilidad con PHP 7.4 y el sistema visual global;
5. no hagas commit, push, limpiezas o cambios destructivos salvo petición explícita.

Si el código real contradice el documento, verifica primero el comportamiento y corrige
el documento en la misma tarea. La petición más reciente del usuario prevalece.
